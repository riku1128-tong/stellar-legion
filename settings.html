2. 公開ゲームに反映する

GitHub のファイルを書き換えて、みんなが遊ぶゲームを新しくします。反映してから 1〜2 分で変わります。

トークンの作り方
  1. GitHub の Fine-grained token を作るページを開く
  2. Repository access で「Only select repositories」を選び、stellar-legion だけを選ぶ
  3. Permissions の Repository permissions で「Contents」を「Read and write」にする
  4. 「Generate token」を押し、出てきたトークンを上の欄に貼る

トークンは GitHub に送るときだけ使い、ほかへは送りません。人に見せないでください。「覚えておく」を外すと、このタブを閉じたときに消えます。
