# STELLAR LEGION（仮組み）

2 つの軍団が宇宙で戦う 2D アクションの試作品。機体の絵はいまは仮の図形で、あとから画像に差し替えられる。

## 概要

- アズール連合（左）とクリムゾン帝国（右）、各 16 機の軍団戦
- プレイヤーが操作するのは自軍の 1 機だけ。ほかの機体は AI が動かす
- 操作中の機体が撃墜されると、近くの味方機に自動で乗り換える。手動でも乗り換えられる
- TIME は 99 から減っていく（初期設定では 2 秒で 1 減る）
- 相手を全滅させたら勝ち。時間切れのときは、残り機数 → 残り HP の合計の順で比べ、それも同じなら引き分け
- 遊び方は 2 種類: 1P VS CPU、1P VS 2P（画面を左右に分割）

## 起動方法

`index.html` を Chrome か Edge で開くだけ。インストールは不要。

## 操作方法

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
|---|---|---|---|
| 移動 | WASD | 矢印キー | 左スティック / 十字キー |
| 主射撃 | J | テンキー1 または `,` | A |
| 副射撃 | K | テンキー2 または `.` | B |
| 格闘 | L | テンキー3 または `/` | X |
| ダッシュ | Space | テンキー0 または 右Shift | RT（RB） |
| 目標切り替え | U | テンキー4 または `;` | Y |
| 乗り換え | I | テンキー5 または `:`（US 配列では `'`） | LT（LB） |

- 狙いは自動で目標（赤い枠）に向く。目標が画面の外にいるときは、画面の端に矢印が出る
- ポーズ: Esc または P（ゲームパッドは Start）。ポーズ中に Q（ゲームパッドは Back）でタイトルに戻る
- 効果音のオン/オフ: M
- 1P VS CPU のときは、矢印キー側のキーとどのゲームパッドでも 1P を操作できる
- 1P VS 2P のときは、1 台目のゲームパッドが 1P、2 台目が 2P
- ダッシュはブーストゲージ（HP の下の水色の線）を使う。離すと回復する

## 機体の種類

| 役割 | 機数 | 特徴 | 武装（主 / 副 / 格闘） |
|---|---|---|---|
| 隊長機 | 1 | バランス型。最初の操作機 | ビームライフル / ミサイル / 格闘 |
| 量産機 | 9 | 標準 | ライフル / なし / 格闘 |
| 砲撃機 | 2 | 遅いが射程が長い | キャノン / ミサイル / なし |
| 戦闘機 | 2 | 速い | 連射砲 / ミサイル / なし |
| 重装機 | 1 | HP が高い | バズーカ / なし / 格闘 |
| 巨大機 | 1 | 大きく HP が非常に高いが遅い | 拡散ビーム / ミサイル / なし |

弾数は時間とともに少しずつ回復する。

## 画像の差し替え方法

1. PNG 画像を `assets` フォルダに置く（**右向き**で描き、背景は透過にする）
2. `js/asset-overrides.js` に、スプライト ID と画像のパスを書く

   ```js
   SL.ASSET_OVERRIDES = {
     'az_grunt': 'assets/az_grunt.png',
     'cr_giant': { src: 'assets/cr_giant.png', scale: 0.5 },        // 大きさを指定
     'cr_fighter': { src: 'assets/cr_fighter.png', facing: 'left' }, // 左向きで描いた画像
   };
   ```

3. `scale` を省くと、元の仮の図形と同じ高さに自動で縮小される
4. 読み込めなかった画像は仮の図形のまま表示され、ブラウザのコンソールに警告が出る
5. 当たり判定は `js/data.js` の `radius` で決まるので、画像を替えてもゲームバランスは変わらない

## 設定の変更

- `js/config.js`
  - `SECONDS_PER_TICK`: TIME が 1 減るまでの秒数（初期値 2）
  - `DAMAGE_SCALE`: 全体のダメージ倍率。小さくすると戦いが長引く（初期値 0.6）
  - `HUMAN_DAMAGE_RATE`: 人間が操作している機体が受けるダメージの倍率（初期値 0.75）
  - `FIELD_W` / `FIELD_H`: 戦場の広さ
- `js/data.js`
  - 機体の HP・速さ・当たり判定・武装、武装の威力・弾数・連射間隔、編成と陣形、勢力の色

いまの数値で AI 同士を 100 試合戦わせた結果: すべて全滅で決着し、試合時間は 46〜113 秒（中央値 76 秒）、勝敗はアズール 43・クリムゾン 57。数値を変えたら、下の `?demo=1` や `SL.game.fastForward()` で様子を見るとよい。

## 開発用の URL パラメータ

ローカルサーバーで開いたときに使える（例: `http://localhost:8000/?demo=1&speed=4`）。

| パラメータ | 内容 |
|---|---|
| `?demo=1` | 両軍とも AI だけで戦う（試合が終わると自動でもう 1 試合） |
| `?speed=4` | 4 倍速（最大 16） |
| `?mode=cpu` / `?mode=2p` | タイトルを飛ばして、その形式で始める |

ブラウザのコンソールで `SL.game.fastForward(200)` を実行すると、描画せずに 200 秒ぶん進めて結果を返す。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（canvas）とスクリプトの読み込み |
| `js/config.js` | 設定値と便利関数 |
| `js/font.js` | 5×7 のドットフォント |
| `js/input.js` | キーボードとゲームパッドの入力 |
| `js/data.js` | 勢力・武装・機体・編成のデータ |
| `js/sprites.js` | 仮の図形の生成と、画像の差し替え |
| `js/asset-overrides.js` | 差し替える画像の一覧 |
| `js/audio.js` | 効果音（WebAudio で合成。音声ファイルなし） |
| `js/effects.js` | 爆発・火花などのエフェクトと星空の背景 |
| `js/entities.js` | 機体と戦場（移動・射撃・格闘・当たり判定・撃墜） |
| `js/ai.js` | 機体の AI |
| `js/hud.js` | 画面の情報表示（機体一覧、TIME、HP、武装、ミニマップ） |
| `js/game.js` | 画面遷移、プレイヤー、カメラ、乗り換え、勝敗判定 |
| `js/main.js` | 起動とゲームループ |
| `assets/` | 差し替え用の画像を置く場所 |
