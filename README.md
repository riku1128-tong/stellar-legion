# STELLAR LEGION（仮組み）

2 つの軍団が宇宙で戦う 2D アクションの試作品。機体と戦艦の絵（`assets/`）は、ローカルの ComfyUI（FLUX.1 schnell）で生成したオリジナルの絵を、背景を抜いてドット絵の大きさに縮小したもの。別の画像にも差し替えられる。

## 概要

- アズール連合（左）とクリムゾン帝国（右）の軍団戦。各軍 16 機（初期設定。1〜30 機に変えられる）と、後方に戦艦が 1 隻
- プレイヤーが操作するのは自軍の 1 機だけ。ほかの機体は AI が動かす
- 操作中の機体が撃墜されると、近くの味方機に自動で乗り換える。Tab でいつでも乗り換えられる
- TIME は 99 から減っていく（初期設定では 2 秒で 1 減る）
- 相手の機体を全滅させたら勝ち。時間切れのときは、残り機数 → 戦艦が残っているか → 残り HP の合計 の順で比べ、それも同じなら引き分け
- 遊び方は 3 種類: 1P VS CPU、1P VS 2P（1 台の画面を左右に分割）、ONLINE（インターネット対戦）
- タイトルの SETTINGS から、機体・武装・出撃の数・絵を変える設定ページ（claude.ai）を開ける

## 起動方法

`index.html` を Chrome か Edge で開くだけ。インストールは不要。
インターネット対戦だけはインターネット接続が必要（PeerJS というライブラリをネットから読み込む）。

## 操作方法

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
|---|---|---|---|
| 移動 | WASD | 矢印キー | 左スティック / 十字キー |
| 主射撃 | J | テンキー1 または `,` | A |
| 副射撃 | K | テンキー2 または `.` | B |
| 格闘 | L | テンキー3 または `/` | X |
| ブースト | Space | テンキー0 または Enter | RT |
| 乗り換え | Tab | テンキー5 または `:`（US 配列では `'`） | LT |
| 変形 | Shift | テンキー6 または 右Shift | LB |
| 目標切り替え | U | テンキー4 または `;` | Y |
| 向きの反転（固定） | 左Ctrl | テンキー7 または 右Ctrl | RB |

- 狙いは自動で目標（四隅のかぎ括弧）に向く。目標が画面の外にいるときは、画面の端に矢印が出る
- 向きは、ふだんは自動で目標の方を向く。Ctrl を押すと左右が反転して、その向きに固定される（武装パネルに `FACE >> FIXED` などと出る）。固定中は前にいる敵だけを狙い、目標が後ろにいるときは撃たずにまっすぐ前へ撃つ。U（目標切り替え）を押すと自動に戻る。変形機の移動モードでは、進む方向を向く
- **注意**: Chrome や Edge では、W を押したまま Ctrl を押すと Ctrl+W（タブを閉じる）として扱われることがある。ページ側では止められないため、対戦中は「このページを離れますか？」の確認が出るようにしてある。Ctrl+S などのほかのショートカットは、ゲーム中は無効になる
- ポーズ: Esc または P（ゲームパッドは Start）。ポーズ中に Q（ゲームパッドは Back）でタイトルに戻る。インターネット対戦中はポーズできず、Q で対戦から抜ける
- 効果音のオン/オフ: M
- 1P VS CPU とインターネット対戦では、矢印キー側のキーとどのゲームパッドでも自分の機体を操作できる
- 1P VS 2P では、1 台目のゲームパッドが 1P、2 台目が 2P

## 動きの仕組み

- **イージング**: 止まった状態から動き出すときはゆっくりで、だんだん加速して巡航速度（機体ごとに一定）になる
- **慣性**: 入力を離しても、すぐには止まらず滑りながら止まる。向きを変えるときも、今の進行方向から少しずつ曲がる。速く動いているほど曲がりにくい（真後ろに切り返すときは、減速してから向きを変える）
- **ブースト**: Space を押している間だけ速くなる（約 1.65 倍）。押している間はブーストゲージ（画面下の水色の線）が減り、離すと少しずつ回復する。使い切ると赤く点滅し、3 割ほど回復するまで使えない
- **変形**（変形できる機体だけ。どの機体を変形できるようにするかは設定ページで決める）: Shift で「戦闘モード」と「移動モード」を切り替える。移動モードは約 1.7 倍速いが、曲がりにくく、格闘できない（武装パネルの格闘欄に LOCK と出る）

## 武装

画面左下の武装パネルに、キー・武装名・残りが出る。

| 種類 | 使うもの | 補充 |
|---|---|---|
| 実弾（マシンライフル、連射砲、キャノン、バズーカ、3WAY / 5WAY / ホーミングミサイル） | 残弾（パネルの数字） | 自然には増えない。自軍の戦艦に入ると補給される |
| ビーム（ビームライフル、拡散ビーム、極太ビームキャノン） | ビームエネルギー（画面下の紫の線。パネルには 1 発ぶんの消費量 `EN12` などが出る） | 撃たずに 1 秒たつと回復が始まる |
| 格闘（ビームサーベル、ヒートアックス、薙刀、ショックウィップ） | なし | — |

- **3WAY / 5WAY ミサイル**: 扇形にまっすぐ飛ぶ
- **ホーミングミサイル**: 目標を追いかける
- **ビームライフル**: 射程が長い
- **極太ビームキャノン**: ボタンを押し続けてチャージし（機体のまわりの輪が縮む）、たまってから離すと発射。射線上の敵をすべて貫く。チャージ中は移動が遅くなり、途中で離すと不発（エネルギーは減らない）
- **ビームサーベル / ヒートアックス**: 敵に向かって突進し、光の刃（ビームサーベルはピンク、ヒートアックスは焼けた斧）を上から下へ振り抜いて斬る。機体の中心から刃先まで 36 ドット、前方およそ 155 度の範囲に当たる。当たると踏み込みは止まり、振り抜きだけ続く
- **薙刀**: 突進しながら長い柄の先の刃を 1 回転ちょっと回し、機体のまわり 46 ドット以内の敵をまとめて斬る
- **ショックウィップ**: 遠くまで伸び、触れた敵をしばらく（0.8 秒）しびれさせて動けなくする。しびれが解けた直後の 1.5 秒間は、もう一度しびれない

## 戦艦

- 各軍の後方に 1 隻ずつ。戦艦は攻撃しない
- 自分が操作している機体で自軍の戦艦に入る（近づくと緑の点線の円と `DOCK` が出る）と、HP・弾・ビームエネルギーが少しずつ回復する。艦内では撃てないが、撃たれもしない
- AI が操作している機体は、自分から戦艦に戻らない
- 敵の戦艦は倒さなくてもよい。倒すとボーナスとして、自軍の全機の HP が最大値の 30% 回復し、弾とビームエネルギーが満タンになる。倒された側は修理できなくなる

初期設定の編成。機体の種類・数・性能・大きさ・武装は、設定ページで変えたり足したりできる。

| 役割 | 機数 | アズール連合 | クリムゾン帝国 |
|---|---|---|---|
| 隊長機 | 1 | VANGUARD: ビームライフル / ホーミング / ビームサーベル | TRIBUNE: ビームライフル / 3WAY / 薙刀 |
| 遊撃機（変形できる） | 2 | FALCON: ビームライフル / 3WAY / ビームサーベル | WASP: 連射砲 / ホーミング / ヒートアックス |
| 重装機 | 1 | BASTION: 極太ビームキャノン / 5WAY / ビームサーベル | JUGGERNAUT: バズーカ / 5WAY / ヒートアックス |
| 量産機 | 7 | GUARD: マシンライフル / なし / ビームサーベル | LEGIONARY: マシンライフル / なし / ヒートアックス |
| 格闘機 | 2 | GLAIVE: マシンライフル / 3WAY / 薙刀 | STINGER: マシンライフル / 3WAY / ショックウィップ |
| 砲撃機 | 2 | MORTAR: キャノン / ビームライフル / なし | HOWITZER: キャノン / ビームライフル / なし |
| 巨大機 | 1 | CITADEL: 拡散ビーム / 5WAY / なし | LEVIATHAN: 拡散ビーム / ホーミング / なし |

武装は「主射撃（J）/ 副射撃（K）/ 格闘（L）」の順。

- **役割**: AI の動き方（好む距離、格闘を仕掛けやすさ）と、陣形のどの列に並ぶかを決める
- **大きさ**: S（ふつう）/ M（絵の長い辺を戦艦の絵にそろえる）/ L（戦艦の 2 倍）。M と L は当たり判定と格闘の届く距離も同じ割合で大きくなる
- **陣形**: 役割ごとに列を作り、数に合わせて自動で並ぶ。並び順が Tab で乗り換える順番。最初に操作するのは隊長機（いなければ一番前の列の 1 機目）

## インターネット対戦

1. 2 人とも同じ URL（例: GitHub Pages の公開 URL）をブラウザで開く
2. 片方がタイトルで `ONLINE` → `CREATE ROOM` を選ぶ。5 文字の部屋コードが出るので、相手に伝える
3. もう片方が `ONLINE` → `JOIN ROOM` を選び、部屋コードを入力して Enter
4. つながると VS 画面になる。部屋を作った側がキーを押すと開始。結果画面で部屋を作った側がキーを押すと再戦、Q で終了

- 部屋を作った側が 1P（左のアズール連合）、入った側が 2P（右のクリムゾン帝国）。どちらも自軍の 1 機を操作し、ほかの機体は AI
- 部屋を作った側のブラウザがゲームを計算し、入った側には 1 秒に 20 回、状態を送る。入った側は自分の操作を 1 秒に 30 回送る
- 相手を見つけるのに PeerJS の公開サーバー（無料・登録不要）を使う。つながったあとはブラウザ同士が直接通信する
- 注意
  - 部屋を作った側は、ゲームのタブを裏に回さないこと（ブラウザが処理を遅くするため、2 人とも動きが遅くなる）
  - 会社のネットワークなど、通信の制限が強い回線ではつながらないことがある
  - 8 秒間相手から何も届かないと、切断として扱う

## 設定ページ（兵器と出撃）

タイトルの `SETTINGS`（または https://claude.ai/artifact/YTenoqEiZoGtxv3XoME23k ）で開く。claude.ai のページなので、持ち主がサインインしているときだけ開ける。

| タブ | できること | 書き換わるファイル |
|---|---|---|
| 機体 | 機体ごとに開閉メニューで、名前・役割・HP・速さ・大きさ（S / M / L）・Shift で変形できるか・J / K / L の武装と、その機体だけの威力と弾数を決める。機体の追加・複製・削除 | `js/units.js` |
| 武装 | 武装ごとの威力・連射間隔・弾数・射程など。刃の色。複製して新しい武装を作る | `js/weapons.js` |
| 出撃 | 各勢力から何をいくつ出すか（1〜30）。開始時の陣形を図で見られる | `js/army.js` |
| 絵 | JPG などの背景を消して切り抜き、機体や戦艦の絵として取り込む | `assets/<ID>.png` と `js/asset-overrides.js` |

- 変えた値はページに自動で保存される。ゲームに入れるには、Claude に「設定を反映して」と頼む（3 つのファイルを書き直し、試合を流して確かめてから公開する）。または、各ファイルの「中身をコピー」で出た内容で、同じ名前のファイルをまるごと置き換える
- 道具: `node tools/settings.js export`（いまのファイルを JSON で出す）、`apply <json>`（JSON から 3 つのファイルを書き直す。おかしな値なら書き込まない）、`check`（書き出しと読み込みで中身が変わらないか確かめる）、`image <ID> <png> <高さ> <幅の上限>`（取り込んだ絵を置いて登録する）

## 画像の差し替え方法

機体と戦艦の絵は `assets` フォルダの PNG（18 枚）。**同じファイル名の画像で上書きするだけで差し替わる。** 設定ページの「絵」タブで切り抜いて取り込むこともできる。

- 画像の大きさは自由。`js/asset-overrides.js` の表で機体ごとに決めた高さ（`height`、ドット）に、自動で縮小・拡大される。横に長すぎる画像は `maxWidth` を超えないようにさらに縮む
- **右向き**で描き、背景は透明にする。左向きの絵なら、その行に `facing: 'left'` を足すと反転して使われる
- ファイル名や場所を変えたいときは、その行の `src` を書き換える（`index.html` からの相対パス）
- 大きさを変えたいときは `height` を変える。当たり判定は `js/units.js` の `radius` で決まるので、ゲームバランスは変わらない（見た目と当たり判定はずれる）
- その行を消すと、コードで描いた仮の図形に戻る。読み込めなかった画像も仮の図形で表示され、ブラウザのコンソールに警告が出る

```js
// いまの設定（assets/az_grunt.png を高さ 26 ドットで出す）
az_grunt: { src: 'assets/az_grunt.png', height: 26, maxWidth: 36 },

// 書き換えの例（別のファイル名・少し大きめ・左向きで描いた絵）
az_grunt: { src: 'assets/my_grunt.png', height: 32, maxWidth: 40, facing: 'left' },
```

いまの表示の高さ（ドット）: 隊長機・重装機 30、変形機 27（移動モード 15）、量産機 26、格闘機 28、砲撃機 23〜25、巨大機 44〜46、戦艦 29〜40。

## 設定の変更

- `js/config.js`
  - `SECONDS_PER_TICK`: TIME が 1 減るまでの秒数（初期値 2）
  - `DAMAGE_SCALE`: 全体のダメージ倍率。小さくすると戦いが長引く（初期値 0.6）
  - `HUMAN_DAMAGE_RATE`: 人間が操作している機体が受けるダメージの倍率（初期値 0.75）
  - `ACCEL_TIME` / `DECEL` / `TURN_SLOW` / `TURN_K`: 加速の速さ、減速の強さ、曲がりやすさ
  - `BOOST_*`: ブーストの倍率・減り方・回復の速さ
  - `EN_REGEN` / `EN_REGEN_DELAY`: ビームエネルギーの回復
  - `DOCK_*` / `SHIP_BONUS_HP`: 戦艦での回復の速さ、撃沈ボーナス
  - `STUN_IMMUNE`: しびれが解けたあと、しびれない秒数
- `js/weapons.js`: 武装の性能（威力・弾数・消費エネルギー・連射間隔・射程など）
- `js/units.js`: 機体（名前・役割・大きさ・HP・速さ・当たり判定・絵・変形・武装）
- `js/army.js`: 各勢力から出撃する機体と数
- `js/data.js`: 勢力の色、役割ごとの AI の性格、戦艦の HP、陣形の並べ方、大きさ（S / M / L）の決まり

武装・機体・出撃は、設定ページで変えるのがかんたん。

数値を変えたら、下の `?demo=1` や `SL.game.fastForward()` で様子を見るとよい。

## 開発用の URL パラメータ

ローカルサーバーで開いたときに使える（例: `http://localhost:8000/?demo=1&speed=4`）。

| パラメータ | 内容 |
|---|---|
| `?demo=1` | 両軍とも AI だけで戦う（試合が終わると自動でもう 1 試合） |
| `?speed=4` | 4 倍速（最大 16） |
| `?mode=cpu` / `?mode=2p` | タイトルを飛ばして、その形式で始める |

ブラウザのコンソールで `SL.game.fastForward(200)` を実行すると、描画せずに 200 秒ぶん進めて結果を返す。
