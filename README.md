# STELLAR LEGION（仮組み）

2 つの軍団が宇宙で戦う 2D アクションの試作品。機体の絵はいまは仮の図形で、あとから画像に差し替えられる。

## 概要

- アズール連合（左）とクリムゾン帝国（右）の軍団戦。各軍 16 機と、後方に戦艦が 1 隻
- プレイヤーが操作するのは自軍の 1 機だけ。ほかの機体は AI が動かす
- 操作中の機体が撃墜されると、近くの味方機に自動で乗り換える。Tab でいつでも乗り換えられる
- TIME は 99 から減っていく（初期設定では 2 秒で 1 減る）
- 相手の機体を全滅させたら勝ち。時間切れのときは、残り機数 → 戦艦が残っているか → 残り HP の合計 の順で比べ、それも同じなら引き分け
- 遊び方は 3 種類: 1P VS CPU、1P VS 2P（1 台の画面を左右に分割）、ONLINE（インターネット対戦）

## 起動方法

`index.html` を Chrome か Edge で開くだけ。インストールは不要。
インターネット対戦だけはインターネット接続が必要（PeerJS というライブラリをネットから読み込む）。

## 操作方法

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
|---|---|---|---|
| 移動 | WASD | 矢印キー | 左スティック / 十字キー |
| 主射撃 | J | テンキー1 または `,` | A |
| 副射撃 | K | テンキー2 または `.` | B |
| 格闘 | L | テンキー3 または `/` | X |
| ブースト | Space | テンキー0 または 右Ctrl | RT（RB） |
| 乗り換え | Tab | テンキー5 または `:`（US 配列では `'`） | LT |
| 変形 | Shift | テンキー6 または 右Shift | LB |
| 目標切り替え | U | テンキー4 または `;` | Y |

- 狙いは自動で目標（四隅のかぎ括弧）に向く。目標が画面の外にいるときは、画面の端に矢印が出る
- ポーズ: Esc または P（ゲームパッドは Start）。ポーズ中に Q（ゲームパッドは Back）でタイトルに戻る。インターネット対戦中はポーズできず、Q で対戦から抜ける
- 効果音のオン/オフ: M
- 1P VS CPU とインターネット対戦では、矢印キー側のキーとどのゲームパッドでも自分の機体を操作できる
- 1P VS 2P では、1 台目のゲームパッドが 1P、2 台目が 2P

## 動きの仕組み

- **イージング**: 止まった状態から動き出すときはゆっくりで、だんだん加速して巡航速度（機体ごとに一定）になる
- **慣性**: 入力を離しても、すぐには止まらず滑りながら止まる。向きを変えるときも、今の進行方向から少しずつ曲がる。速く動いているほど曲がりにくい（真後ろに切り返すときは、減速してから向きを変える）
- **ブースト**: Space を押している間だけ速くなる（約 1.65 倍）。押している間はブーストゲージ（画面下の水色の線）が減り、離すと少しずつ回復する。使い切ると赤く点滅し、3 割ほど回復するまで使えない
- **変形**（変形できる機体だけ）: Shift で「戦闘モード」と「移動モード」を切り替える。移動モードは約 1.7 倍速いが、曲がりにくく、格闘できない（武装パネルの格闘欄に LOCK と出る）

## 武装

画面左下の武装パネルに、キー・武装名・残りが出る。

| 種類 | 使うもの | 補充 |
|---|---|---|
| 実弾（マシンライフル、連射砲、キャノン、バズーカ、3WAY / 5WAY / ホーミングミサイル） | 残弾（パネルの数字） | 自然には増えない。自軍の戦艦に入ると補給される |
| ビーム（ビームライフル、拡散ビーム、極太ビームキャノン） | ビームエネルギー（画面下の紫の線。パネルには 1 発ぶんの消費量 `EN12` などが出る） | 撃たずに 1 秒たつと回復が始まる |
| 格闘（ビームサーベル、ヒートアックス、薙刀、ショックウィップ） | なし | — |

- **3WAY / 5WAY ミサイル**: 扇形にまっすぐ飛ぶ
- **ホーミングミサイル**: 目標を追いかける
- **ビームライフル**: 射程が長い
- **極太ビームキャノン**: ボタンを押し続けてチャージし（機体のまわりの輪が縮む）、たまってから離すと発射。射線上の敵をすべて貫く。チャージ中は移動が遅くなり、途中で離すと不発（エネルギーは減らない）
- **ビームサーベル / ヒートアックス**: 敵に向かって突進して斬る
- **薙刀**: 突進しながら回転し、周りの敵をまとめて斬る
- **ショックウィップ**: 遠くまで伸び、触れた敵をしばらく（0.8 秒）しびれさせて動けなくする。しびれが解けた直後の 1.5 秒間は、もう一度しびれない

## 戦艦

- 各軍の後方に 1 隻ずつ。戦艦は攻撃しない
- 自分が操作している機体で自軍の戦艦に入る（近づくと緑の点線の円と `DOCK` が出る）と、HP・弾・ビームエネルギーが少しずつ回復する。艦内では撃てないが、撃たれもしない
- AI が操作している機体は、自分から戦艦に戻らない
- 敵の戦艦は倒さなくてもよい。倒すとボーナスとして、自軍の全機の HP が最大値の 30% 回復し、弾とビームエネルギーが満タンになる。倒された側は修理できなくなる

## インターネット対戦

1. 2 人とも同じ URL（例: GitHub Pages の公開 URL）をブラウザで開く
2. 片方がタイトルで `ONLINE` → `CREATE ROOM` を選ぶ。5 文字の部屋コードが出るので、相手に伝える
3. もう片方が `ONLINE` → `JOIN ROOM` を選び、部屋コードを入力して Enter
4. つながると VS 画面になる。部屋を作った側がキーを押すと開始。結果画面で部屋を作った側がキーを押すと再戦、Q で終了

- 部屋を作った側が 1P（左のアズール連合）、入った側が 2P（右のクリムゾン帝国）。どちらも自軍の 1 機を操作し、ほかの機体は AI
- 部屋を作った側のブラウザがゲームを計算し、入った側には 1 秒に 20 回、状態を送る。入った側は自分の操作を 1 秒に 30 回送る
- 相手を見つけるのに PeerJS の公開サーバー（無料・登録不要）を使う。つながったあとはブラウザ同士が直接通信する
- 注意
  - 部屋を作った側は、ゲームのタブを裏に回さないこと（ブラウザが処理を遅くするため、2 人とも動きが遅くなる）
  - 会社のネットワークなど、通信の制限が強い回線ではつながらないことがある
  - 8 秒間相手から何も届かないと、切断として扱う

## 画像の差し替え方法

1. PNG 画像を `assets` フォルダに置く（**右向き**で描き、背景は透過にする）
2. `js/asset-overrides.js` に、スプライト ID と画像のパスを書く

   ```js
   SL.ASSET_OVERRIDES = {
     'az_grunt': 'assets/az_grunt.png',
     'cr_giant': { src: 'assets/cr_giant.png', scale: 0.5 },              // 大きさを指定
     'cr_raider_jet': { src: 'assets/cr_raider_jet.png', facing: 'left' }, // 左向きで描いた画像
   };
   ```

3. `scale` を省くと、元の仮の図形と同じ高さに自動で縮小される
4. 読み込めなかった画像は仮の図形のまま表示され、ブラウザのコンソールに警告が出る
5. 当たり判定は `js/data.js` の `radius` で決まるので、画像を替えてもゲームバランスは変わらない

### スプライト ID

| ID | 絵 |
|---|---|
| az_commander / cr_commander | 隊長機 |
| az_raider / cr_raider | 変形機（戦闘モード） |
| az_raider_jet / cr_raider_jet | 変形機（移動モード） |
| az_heavy / cr_heavy | 重装機 |
| az_grunt / cr_grunt | 量産機 |
| az_special / cr_special | 格闘機（薙刀 / ショックウィップ） |
| az_artillery / cr_artillery | 砲撃機 |
| az_giant / cr_giant | 巨大機 |
| az_ship / cr_ship | 戦艦 |

`az_` がアズール連合、`cr_` がクリムゾン帝国。

## 設定の変更

- `js/config.js`
  - `SECONDS_PER_TICK`: TIME が 1 減るまでの秒数（初期値 2）
  - `DAMAGE_SCALE`: 全体のダメージ倍率。小さくすると戦いが長引く（初期値 0.6）
  - `HUMAN_DAMAGE_RATE`: 人間が操作している機体が受けるダメージの倍率（初期値 0.75）
  - `ACCEL_TIME` / `DECEL` / `TURN_SLOW` / `TURN_K`: 加速の速さ、減速の強さ、曲がりやすさ
  - `BOOST_*`: ブーストの倍率・減り方・回復の速さ
  - `EN_REGEN` / `EN_REGEN_DELAY`: ビームエネルギーの回復
  - `DOCK_*` / `SHIP_BONUS_HP`: 戦艦での回復の速さ、撃沈ボーナス
  - `STUN_IMMUNE`: しびれが解けたあと、しびれない秒数
- `js/data.js`
  - 武装の威力・弾数・消費エネルギー・連射間隔、機体の HP・速さ・当たり判定・武装・変形、戦艦の HP、編成と陣形、勢力の色

数値を変えたら、下の `?demo=1` や `SL.game.fastForward()` で様子を見るとよい。

## 開発用の URL パラメータ

ローカルサーバーで開いたときに使える（例: `http://localhost:8000/?demo=1&speed=4`）。

| パラメータ | 内容 |
|---|---|
| `?demo=1` | 両軍とも AI だけで戦う（試合が終わると自動でもう 1 試合） |
| `?speed=4` | 4 倍速（最大 16） |
| `?mode=cpu` / `?mode=2p` | タイトルを飛ばして、その形式で始める |

ブラウザのコンソールで `SL.game.fastForward(200)` を実行すると、描画せずに 200 秒ぶん進めて結果を返す。

|---|---|

| `js/config.js` | 設定値と便利関数 |
| `js/font.js` | 5×7 のドットフォント |

| `js/data.js` | 勢力・武装・機体・戦艦・編成のデータ |

| `js/asset-overrides.js` | 差し替える画像の一覧 |
| `js/audio.js` | 効果音（WebAudio で合成。音声ファイルなし） |
| `js/effects.js` | 爆発・火花などのエフェクトと星空の背景 |
| `js/entities.js` | 機体・戦艦・戦場（移動、ブースト、変形、射撃、格闘、当たり判定、修理） |
| `js/ai.js` | 機体の AI |
| `js/hud.js` | 画面の情報表示（機体一覧、TIME、HP、エネルギー、ブースト、武装、ミニマップ） |

| `js/main.js` | 起動とゲームループ |
| `assets/` | 差し替え用の画像を置く場所 |
